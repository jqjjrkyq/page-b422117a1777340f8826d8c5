客户端选择与官网下载

迷途云订阅兼容主流 Clash / Sing-Box 生态与常见 iOS 商店客户端。请优先从各客户端官方渠道获取安装包，再用本站订阅链接导入。本页强调「先选客户端、再导入订阅」，减少协议不匹配导致的连不上问题。

Windows

推荐 Clash Verge Rev 或 v2rayN。安装后选择「从 URL 更新订阅」，粘贴机场订阅地址，开启系统代理或 TUN。若只需浏览器加速，可仅开系统代理；游戏与 UDP 场景建议 TUN。

macOS

轻量场景用 ClashX.Meta；需要规则集与策略组细控时用 Surge。导入后检查「允许局域网」与 DNS 劫持是否符合公司网络策略。Apple Silicon 请使用对应架构构建，避免转译导致的异常耗电。

iOS / iPadOS

常用 Shadowrocket、Stash、Quantumult X。通过 Safari 打开订阅或在应用内「从 URL 下载」。蜂窝网络下请关闭「低数据模式」干扰，流媒体解锁以旗舰版全节点原生解锁为准。

Android

推荐 Clash Meta for Android。开启 VPN 模式后授予通知与自启动（按厂商设置），避免休眠断连。如需分应用代理，在访问控制中仅勾选需要加速的应用。

路由器与软路由

OpenClash、HomeProxy、Clash Meta 内核均可订阅同一地址。团队版可配合定制路由，把办公网段与游戏网段拆到不同策略组。请勿把订阅明文写进可被访客读取的配置页。

「官网下载」在此指：客户端安装包走上游官方发布页，迷途云侧只提供订阅与节点；不要从来路不明的网盘获取修改版客户端。

使用场景

跨境协作与资料检索

基础版即可覆盖邮件、文档与常规会议。节点池以香港、新加坡、日本、美国西岸为主，延迟随当时负载变化。若会议对丢包敏感，将会议应用单独走延迟更低的线路，而不是全局同一节点。

流媒体

基础版提供基础流媒体解锁；旗舰版与团队版为全节点原生解锁，减少「能打开首页但不能播」的地区库问题。请避免同一账号在短时间切换过多出口地区。

游戏与实时对战

旗舰版含 IPLC 专线游戏加速优化，适合对延迟和抖动更敏感的对战与更新下载。UDP 转发需在客户端开启对应开关。团队版可将游戏设备与办公设备拆分会话，避免抢占带宽。

小团队共享

团队版 20 台同时在线与 1000GB 月流量面向工作室或项目组。定制路由用于把代码仓库、设计素材源站与普通网页分成不同出口，降低误走高延迟线路的情况。

操作说明

  1. 在套餐区确认流量、设备数与是否需要 IPLC / 原生流媒体，开通对应档位。
  2. 在账户中心复制订阅 URL（Clash 与通用订阅通常分列，按客户端选择）。
  3. 进入上方「客户端选择」，安装与系统匹配的官方客户端，不要混用过期内核。
  4. 客户端内选择从 URL 导入或更新，首次建议手动更新一次规则集。
  5. 连通性测试：先选一条标注「普通」或「IEPL/IPLC」的节点访问状态页，再切到流媒体或游戏策略。
  6. 若失败：检查系统时间、本地防火墙、是否多客户端抢占 TUN，以及设备数是否已满。

节点与线路

普通线路节点池覆盖日常浏览；旗舰版起开放 IPLC 游戏向节点与原生流媒体出口。名称中的地区为入口或中转标注，实际播放版权库以解锁策略为准。不在此页公布实时负载数字，以免过期信息误导。

工单

旗舰版为 7x24 优先工单；团队版另有专属客户经理通道。提交时请附上客户端名称与版本、系统、订阅类型、失败节点名与本地测试时间，便于核对是否为协议或规则问题。

常见问题

迷途云(Stray)如何选择客户端？

按系统选：Windows 用 Clash Verge 或 v2rayN；macOS 用 ClashX.Meta 或 Surge；iOS 用 Shadowrocket、Stash 或 Quantumult X；Android 用 Clash Meta for Android。先装官方客户端，再导入订阅，是减少故障的最有效顺序。

订阅导入后没有节点或无法更新？

核对复制的是完整 HTTPS 订阅地址、客户端是否支持该订阅格式，以及本地时间是否准确。更新失败时先关闭系统代理再重试，避免客户端更新流量被自己的错误代理劫持。仍失败请更换网络后重试一次。

基础版、旗舰版、团队版怎样区分？

基础版 100GB / 3 设备 / 基础流媒体 / 普通节点池，适合轻度使用。旗舰版 300GB / 5 设备 / 全节点原生流媒体 / IPLC 游戏优化 / 优先工单。团队版 1000GB / 20 设备 / VIP 高带宽与定制路由，面向多人同时在线。

流量与设备数如何计算？是否清零？

流量按成功转发字节月度累计，到期按套餐周期重置。设备数统计同时在线会话，不是历史绑定台数。达到上限后新会话无法建立，可下线空闲设备后重连。年付只影响结算，不影响额度。

能否用于游戏加速和流媒体？

可以。游戏相关请优先旗舰版 IPLC 优化节点并开启 UDP。流媒体在基础版为有限解锁，旗舰版与团队版为全节点原生解锁。若某一节目仍受版权库限制，更换同区域其他节点，而不是反复开关客户端。

在哪里进行官网下载？是否提供修改版安装包？

迷途云官方网站只提供订阅与说明；客户端安装包请到对应项目的官方发布页获取。本站不提供修改版、破解版或第三方打包客户端，以避免凭证泄露与异常分流。
